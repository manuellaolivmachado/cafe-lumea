# ☕ Café Lumea

Projeto de um site para uma cafeteria, desenvolvido para praticar:
HTML, CSS e JavaScript.

## 💻 Tecnologias

- HTML
- CSS
- JavaScript

## ✨ Funcionalidades

- Visualização do cardápio
- Seleção de bebidas e comidas
- Adição de produtos ao pedido
- Visualização da conta
- Finalização do pedido

## 👩‍💻 Sobre o projeto

Este projeto foi desenvolvido por mim como forma de colocar em
prática meus conhecimentos de HTML, CSS e JavaScript.

O JavaScript foi utilizado para desenvolver a lógica do sistema
de pedidos e a interação entre as diferentes partes do site.

## 📚 O que pratiquei

- Estruturação de páginas com HTML
- Estilização com CSS
- Lógica de programação com JavaScript
- Funções e condicionais
- Manipulação da interação do usuário
